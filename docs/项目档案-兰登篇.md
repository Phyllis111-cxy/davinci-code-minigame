## 2. 玩法总案：方案 1 · 三幕推进

混合玩法：**对话发现线索 → 探案墙连线（含推理）→ 1 个收尾轻谜题（双环转盘）**。

```
intro（对话入局）
  → discover（检视线索）
  → assembleWord（偏旁拼「圣杯」）
  → linking（三步推理连线 + 教堂干扰钉）
  → ending（epilogue 通关旁白 → cta：索菲预告 + 购买 + 再玩）
```

### 幕一 · 入局（约 40 秒）

- 兰登短对话开场：画作与纹章在「互相指认」。
- 点按推进台词 → 检视第一件证物 → 线索钉上探案墙。
- 教学目标：对话 / 检视会产生墙上线索。

### 幕二 · 探案墙（约 2～3 分钟）

- 固定钉位（**不可解谜阶段自由拖动**）。
- 含：**偏旁拼字**（中文关键词 + 外文仅装饰）+ **带逻辑锁的连线**。
- 5 钉（含 1 个字面干扰）。

### 通关 · 两页收束

- 连线完成后直达通关，无密码筒。
- **第 1 页（epilogue）**：探案墙 + 兰登通关旁白，点屏幕继续。
- **第 2 页（cta）**：索菲预告 + 购买入口 + 再玩一次（无分享）。

## 3. 角色与文案口吻

| 角色 | 作用 |
|------|------|
| 玩家 | 兰登的搭档，点选、拼字、连线 |

| 索菲·奈芙 | 仅通关预告卡；本集不入局 |

### 提示兜底（保持「不要太难」）

- 连错 **2 次**：学者式提问提示（不直接给答案）。
- 再错：高亮下一正确端点。
- 可回墙查看线索；**不限时**。
- 卡关时语气可略偏温和导师，但不改默认学者人设。

## 4. 探案墙 · 五钉定案

钉位**固定布局**。通关页直接展示当前探案墙，不再生成分享图。

| ID | 名称 | 玩家所见 | 推理用途 |
|----|------|----------|----------|
| A | 《她的手势》笔记 | 剪影式画作便签，手势被圈出 | 手势 =「守护」姿态 |
| B | 玫瑰纹章残片 | 简化玫瑰 + 中文旁注；角落可有极小外文装饰 | 玫瑰 =「守护/隐秘」记号（不是终点） |
| C | 拆字便签 | 关键词 **「圣杯」** 偏旁/部件拆开；外文只装饰 | 拼对后成为「被守护对象」之名 |
| D | 指向卡 · 血脉 | 初可为「？」；关键步骤后揭示 | **正确终点**：杯的隐喻 = 血脉/传承 |
| E | 指向卡 · 教堂 | 看起来很像「标准答案」 | **干扰钉**：字面建筑陷阱 |

### 视觉与内容边界

- 软木 / 牛皮纸探案墙、红线、便签、大头针。
- 避免未授权剧照、名画高清原图、大段照搬小说对白。
- 外文**不参与判定**；中国玩家只靠中文与符号操作通关。
- 主题用符号隐喻呈现，避免说教或敏感展开。

|----|------|

## 6. 连线推理（方案 B · 加干扰钉）

### 操作

- 手机友好：**点选钉 → 再点另一钉** 拉红线（优于长按拖拽）。
- 连对：线锁定 + 短反馈 + 兰登一句点评。
- 连错：线消失；累计错误触发提示。

### 正确三组（必须按逻辑推进）

1. **A ↔ B**  
   证明：手势的「守护」与玫瑰的「守护记号」同属一套守护符号语言。  
   → 还不是终点。

2. **B ↔ C**  
   证明：守护记号所护之物，落在拼出的「圣杯」上。  
   → 仍未解释「杯」是什么。

3. **C ↔ D**  
   证明：若杯是隐喻容器，则指向「血脉/传承」，而非建筑。

### 逻辑锁

- 未完成第 1 组前，第 2、3 组不可生效（提示「还缺一环」）。
- 未完成第 2 组前，第 3 组不可生效。
- **C ↔ E**（及任何以教堂为「圣杯所指」的连线）**恒为错**：兰登「太字面了。」
- 思维链（给策划/文案用，不必原样展示给玩家）：  
  **守护符号成立 → 对象名为圣杯 → 圣杯隐喻血脉（排除教堂）。**

### 为何比「邻钉互连」更有探案感

- 每条线索带可核对的属性句，不能只靠位置蒙对。
- 干扰钉提供「像正确答案」的排除题。
- 顺序锁迫使玩家完成推理链，而不是乱连。

## 7. 幕三 · 双环转盘（Cryptex UI）

| 项 | 定案 |
|----|------|
| 形态 | 左右（或上下）两环，每环 3～4 格 |
| 左环 | 本关已出现符号；**正确 = 玫瑰**（与 B 一致） |
| 右环 | 中文词；**正确 = 圣杯** |
| 设计原则 | 只确认玩家**已经用连线证明过**的对应，不考新知识 |
| 开场旁白 | 「密码筒只认你已经证明过的对应。」 |
| 失败 | 错 2 次正确格微光；可回墙；不限时 |

**不采用**：收尾三选一选择题（曾讨论，已否决）。
