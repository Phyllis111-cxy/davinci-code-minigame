# 《达芬奇密码》宣传小游戏

手机网页向宣传小游戏。系列计划两集：

| 篇章 | 带领者 | 侧重点 | 状态 |
|------|--------|--------|------|
| 第一集 | 罗伯特·兰登 | 圣杯线索线 · 探案墙连线 · 轻解密 | 骨架可跑通 |
| 第二集 | 索菲·奈芙 | 密码破译 / 现场线 | 预告页 `/sophie` |

## 本地运行

```bash
npm install
npm run dev
```

手机访问终端提示的局域网地址即可。

```bash
npm run build
```

## 源码结构（骨架）

```
src/
  data/langdon-01.json   # 关卡数据
  game/                  # 状态机 / 判定 / 截图
  components/            # 对话、探案墙、拼字、转盘、通关
  pages/                 # 兰登篇、索菲预告
```

## 一句话定位

兰登带玩家在探案墙上拼线索、做轻度推理连线，再用双环「密码筒」确认已证明的对应关系；通关可分享线索图，并引导购买与索菲篇预告。
